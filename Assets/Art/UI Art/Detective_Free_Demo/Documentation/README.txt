Detective Icons - Free Demo

Contents
- 20 unique designs: 14 detective-themed items and 6 matching UI graphics.
- Each design is supplied in color and grayscale: 40 image variants.
- Individual static 256 x 256 pixel, 8-bit RGBA PNG images with transparency.
- 20 categories, 1 design(s) per category.
- Each variant appears in two organizational views: 80 PNG files plus
  README.txt, PREVIEW.txt and LICENSE.txt; 83 files total.

The collection covers detective tools, evidence collection, forensic analysis,
physical clues, case documents, locks, surveillance gear, detective clothing,
office equipment, recovered objects, storage, investigation props, case progress,
rewards and matching interface actions. UI graphics are standalone symbols with
a coordinated navy, brass, cream and burgundy cartoon palette.

Folder guide
- All_Icons/: all 20 color icons.
- Icons_By_Category/: the same color icons organized by category.
- Grayscale_Icons/All_Icons/: all 20 grayscale variants.
- Grayscale_Icons/Icons_By_Category/: the same grayscale variants by category.
- Documentation/: these three shared documents.

There are 20 unique icon designs, not 80. Color/grayscale are variants;
All_Icons and Icons_By_Category are duplicate organizational views. Choose one
view and the desired variant when importing. Grayscale files preserve the
corresponding color image's filename, size, placement and exact transparency.
See PREVIEW.txt for the exact included names and category folders.

The demo includes one design per category, using the exact color and grayscale
PNG files from the full pack. The full collection contains 180 designs.

Usage
1. Read LICENSE.txt.
2. Import the desired PNGs using your game engine or image tool's workflow.
3. Preserve proportions and transparency when resizing.
4. Assign images to your inventory, clues, case files, rewards and UI controls;
   implement your own labels and behavior in your project.

These are static images, not animated sprites, 3D models, scripts or functional
buttons. Game behavior and engine-specific import settings are not included.
Original generic cartoon artwork; no official Roblox affiliation is implied.
